# 反馈层奖惩标准（初始值，供校准）

说明: 基础分 100；以下事件增减分。用户校准准则：**鼓励高效击杀/推塔/生存，重罚无脑送死/空转浪费**。

## 奖励
| 事件 | 分 | 说明 |
|---|---|---|
| 击杀 kill | +20 | 击杀敌方英雄（本局目标：单杀≥2） |
| 助攻 assist | +15 | 参与击杀 |
| 推塔 tower_kill | +10 | 我方拆除敌方防御塔 |
| 清兵 minion_clear | +2 | 补刀敌方小兵（防止过度刷兵扣分待定） |
| 大招/连招使用 ult_combo | +5 | 成功放出 勾→晕→大 完整连招 |
| 成功撤退存活 escape_alive | +5 | 低血安全脱离（未死） |

## 惩罚
| 事件 | 分 | 说明 |
|---|---|---|
| 阵亡 died | -50 | 死亡（用户标准：送死重罚） |
| 被塔打 be_tower_attacked | -20 | 塔攻击范围内硬吃塔伤（= 脱逃失败） |
| 被攻击 be_attacked | -3 | 每次挨打（累计=接团战损） |
| 空转浪费浪费_状态 wasted_skill | -2 | 无目标释放技能（防空钩） |
| 未恢复未回城 | -5 | 血蓝<80% 未用恢复 / <15% 未回城（在安全时）|

## 学习目标（用户手打局为基准）
- 评分 ≥ 8.0（用户局 MVP 水平）、KDA 击杀≥2/死亡≤1/助攻≥2
- 参团率 ≥ 60%、输出占比 ≥ 15%（钟馗辅助位）
- 全图支援：中/下路 45/45；无上路无脑单机

## 待用户校准项
1. 各事件分值（可整体缩放）
2. 是否增加"资源控制"（龙/兵线权重）
3. 团战不参战惩罚
